# 🎨 Themes Google

Este repositório contém temas personalizados desenvolvidos para o navegador **Google Chrome**, com foco em estilos únicos como **Pixel Art** e **Psicodélico**.

## 📦 Conteúdo do Repositório

O repositório está organizado em pastas, cada uma contendo um tema:

- `Pixelart/`
- `Pscicodelico/`

Cada tema inclui:

- `.crx`: pacote de extensão instalável
- `.pem`: chave privada gerada na criação do tema
- `manifest.json`: arquivo de configuração do tema
- `/images`: imagens usadas no tema (backgrounds, toolbar, abas, etc.)

## 🧪 Pré-visualização

Cada tema inclui as seguintes imagens:

- `theme_frame.png`
- `theme_ntp_background.png`
- `theme_tab_background.png`
- `theme_toolbar.png`

Essas imagens compõem a aparência visual do tema dentro do navegador Chrome.

## 🚀 Como instalar os temas

1. Baixe o arquivo `.crx` do tema desejado.
2. Acesse o Chrome e vá em `chrome://extensions/`.
3. Ative o **Modo do desenvolvedor** (canto superior direito).
4. Arraste e solte o arquivo `.crx` na página de extensões.
5. Confirme a instalação.

> ⚠️ O Google Chrome pode bloquear a instalação direta de `.crx` dependendo das políticas de segurança. Uma alternativa é carregar o tema descompactado:

### Instalar manualmente como tema descompactado:

1. Acesse `chrome://extensions/`
2. Ative o **Modo do desenvolvedor**
3. Clique em **"Carregar sem compactação"**
4. Selecione a pasta do tema (ex: `Pixelart/theme1727297063/`)
